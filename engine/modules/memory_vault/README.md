# Memory Vault

This folder contains a minimal scaffold for integrating a Memory Vault using Neo4j (graph metadata) and ChromaDB (vector store).

- `neo4j_client.py`: lightweight Neo4j wrapper
- `chroma_store.py`: lightweight ChromaDB wrapper
- `memory_manager.py`: unified API for store/query operations

Install runtime deps when using this scaffold: `pip install neo4j chromadb`
